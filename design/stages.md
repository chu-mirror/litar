The implementations before the final stage do not have to implement

# Bootstrap

Implement the design till and include section "Filters" in `design/litar.md` as `src/boot.c`.
The filters are run under current working directory as normal scripts.

The implementation should be able to extract `path to perl interpreter` from `lib/text-processing.la`,
which is the path to an executable perl interpreter.
